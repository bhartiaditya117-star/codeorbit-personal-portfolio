# Personal Portfolio Website

## Project Overview

This is a responsive personal portfolio website created as part of my CodeOrbit Tech Web Development Internship.

The website showcases my profile, skills, projects, and contact information in a clean and responsive design.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive design for desktop and mobile
- About Me section
- Skills section
- Projects section
- Contact section
- Interactive navigation
- Responsive mobile menu
- Contact form with JavaScript interaction
- Clean and modern user interface
