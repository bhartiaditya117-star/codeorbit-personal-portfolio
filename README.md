# Personal Portfolio Website

## Project Overview

This project is a responsive personal portfolio website developed as part of my **CodeOrbit Tech Web Development Internship**.

The website presents my profile, skills, projects, education information, and contact details in a clean and responsive interface.

## Features

* Responsive navigation bar
* Home/Hero section
* About Me section
* Skills section
* Projects section
* Contact section
* Responsive design for desktop, tablet, and mobile
* Mobile navigation menu using JavaScript
* Contact form validation
* Modern dark-themed user interface
* Smooth scrolling navigation

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Git
* GitHub
